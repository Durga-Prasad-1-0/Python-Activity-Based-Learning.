## Overview

This assignment contains 10 Python programming tasks. Each task includes
Python source code, a flowchart, and an output example in the assignment
PDF.

## Tasks Included

1.  **Attendance and Extra Classes Calculator** -- Calculates current
    attendance and the extra classes required to reach the target
    percentage.
2.  **Bank Account Management System** -- Provides deposit, withdrawal,
    balance-checking, and exit options.
3.  **Exam Performance and Improvement Tracker** -- Calculates the
    average marks, improvement, and performance category for three
    exams.
4.  **Travel Cost Comparison for Vehicles** -- Estimates fuel required
    and travel cost for a bike, car, and mileage car, then identifies
    the cheapest option.
5.  **Number Pattern Printing** -- Prints an increasing and decreasing
    number pattern for the selected number of rows.
6.  **Password Strength Validator** -- Checks password length and the
    presence of uppercase letters, lowercase letters, digits, and
    special characters.
7.  **String Examination Answer Evaluation** -- Compares answers with an
    answer key and calculates correct, wrong, unanswered, and final
    score totals.
8.  **String Compression Analyzer** -- Compresses consecutive repeated
    characters and compares the compressed length with the original
    length.
9.  **Student Marks and Subject Average Analyzer** -- Calculates student
    averages, identifies the top student, and calculates subject
    averages.
10. **Food Wastage Tracker** -- Calculates daily leftover meals and
    wastage percentages, and reports overall wastage.

## Requirements

-   Python 3
-   A Python editor or IDE, such as IDLE, Visual Studio Code, or PyCharm

## How to Run

1.  Save each task's Python code in its own `.py` file.

2.  Open a terminal or command prompt in the folder containing the file.

3.  Run the required task with:

    ``` bash
    python filename.py
    ```

4.  Enter the values requested by the program and review the displayed
    output.

On Windows, `py filename.py` can also be used if the Python launcher is
installed.
